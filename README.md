# skills

Agent skills, one directory each. Install one globally with the [skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills@latest add git@github-skills:matias-pizarro/skills.git -g -a pi claude-code --skill review-loop
```

The `github-skills` host is an SSH alias for a deploy key while this repo is private. Skills are MIT licensed; see [LICENSE](LICENSE).
